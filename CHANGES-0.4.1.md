# Perubahan KLIK 0.4.1

- Kartu event pada Beranda mengikuti tinggi kartu dengan isi terpanjang. Tombol bagian bawah sejajar meskipun judul dan lokasi memiliki panjang berbeda.
- Tombol ruang menggunakan lebar kartu untuk merapat ke sisi kanan. Teks tombol ruang adalah Gabung, termasuk pada kartu kegiatan milik sendiri.
- Label Kasual/Berperingkat rata kanan. Harga event ikut rata kanan.
- Teks tombol event tetap Lihat Acara atau Lihat Detail sesuai keikutsertaan.
- Pada layar kecil dengan tulisan besar, informasi slot dan tombol disusun vertikal agar dapat dibaca.
- Nomor versi di pengaturan diperbarui menjadi 0.4.1.

Pemeriksaan: analisis kode tanpa masalah; 47 pemeriksaan aturan/penyimpanan serta 12 tes konfigurasi, navigasi, kegagalan penyimpanan, tata letak dan pengiriman skor lulus. Tiga tes tambahan memeriksa kesamaan ukuran kartu, perataan tombol/label dan teks 200%. Gambar layar utama terang/gelap ditinjau. Hasil ini tidak menjamin seluruh bug pada seluruh perangkat telah ditemukan.

Data uji coba menggunakan penyimpanan lokal. Pengujian server PostgreSQL dan multi-pengguna memerlukan database PostgreSQL yang belum tersedia.
