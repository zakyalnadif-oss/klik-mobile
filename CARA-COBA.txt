CARA MENCOBA KLIK 0.4.3 DI HP ANDROID

APK terbaru: KLIK-0.4.3-Testing.apk

Untuk contoh alur QRIS:
1. Buka KLIK dan pilih Coba tanpa akun.
2. Pada Ruang Terdekat, pilih Gabung di pertandingan berbayar, misalnya Futsal Cilandak Berperingkat.
3. Halaman Pembayaran langsung menampilkan QR dan nominal pertandingan.
4. Gulir ke bawah, lalu tekan Konfirmasi pembayaran.
5. Pendaftaran selesai dan peserta masuk ke pertandingan.
6. Coba juga Batalkan: peserta tidak akan bergabung.

Untuk event, buka Lihat Acara, kemudian Daftar Event untuk melihat QR. Pertandingan gratis tidak menampilkan pembayaran.

QR ini hanya untuk contoh tampilan: isinya data JSON, bukan kode QRIS pembayaran bank/dompet digital. Tidak ada uang yang dikirim atau diterima. Konfirmasi dilakukan lokal melalui tombol, bukan pemeriksaan transaksi Midtrans. Tulisan Simulasi tidak ditampilkan pada layar pembayaran.

Pemasangan APK:
- Pindahkan KLIK-0.4.3-Testing.apk ke HP, lalu buka melalui Files/File Manager dan pilih Instal.
- APK uji coba memakai sertifikat sementara. Jika Android menolak pembaruan langsung, aplikasi lama perlu dicopot sebelum memasang versi ini. Pencopotan menghapus data lokal; lakukan hanya jika data percobaan memang boleh dihapus.

Kode sumber berada di folder lib. Buka folder KLIK-Flutter melalui File > Open Folder di VS Code. Catatan versi ini: CHANGES-0.4.3.md. Hasil pemeriksaan: VALIDATION.md.

Untuk mencoba input skor dua ketua: buka Profil > Pengaturan > Coba input dua ketua. Isi 5–3 sebagai Ketua Tim Merah, lalu isi 5–3 sebagai Ketua Tim Biru. Hasil menjadi Disahkan. Skor yang berbeda belum disahkan. Halaman contoh tidak mengubah hasil room kamu. Rincian: CARA-UJI-SKOR.md.
