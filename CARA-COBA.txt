CARA MEMASANG KLIK 0.4.1 DI HP ANDROID

APK terbaru: KLIK-0.4.1-Testing.apk

Versi sebelumnya memakai kunci APK sementara, sehingga Android dapat menolak pembaruan langsung. Untuk mengganti versi lama pada percobaan ini:
1. Pastikan data percobaan lama memang boleh dihapus. Data lokal ikut terhapus ketika aplikasi dicopot.
2. Di HP, tekan lama ikon KLIK, lalu pilih Uninstall/Copot pemasangan.
3. Pindahkan KLIK-0.4.1-Testing.apk dari folder LOMBA/KLIK-Flutter ke HP.
4. Buka APK melalui Files/File Manager, lalu pilih Instal.
5. Jika Android meminta izin memasang dari pengelola file tersebut, berikan izin untuk pemasangan APK ini.
6. Buka KLIK, lalu pilih Coba tanpa akun.

Coba kembali:
- Buat event dengan judul pendek dan panjang, lalu lihat kartu event di Beranda. Tinggi kartu harus sama.
- Buka Ruang Terdekat. Label Kasual/Berperingkat dan tombol Gabung berada di sisi kanan kartu.
- Ganti tema terang/gelap dan coba ukuran tulisan besar.

Data tersimpan di HP ini. Akun online dan data bersama belum aktif karena proyek Supabase belum tersedia.

Kode sumber berada di folder lib. Untuk mengedit, buka folder KLIK-Flutter melalui File > Open Folder di VS Code. Catatan perubahan ada di CHANGES-0.4.1.md; hasil pemeriksaan ada di VALIDATION.md.
